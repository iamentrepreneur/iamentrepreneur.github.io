# DESIGN — визуальная спецификация

## Концепция
Минималистичный editorial / engineering portfolio. Ориентир — чистая типографика, аккуратные сетки, много воздуха, читаемые технические кейсы. Сайт должен восприниматься как профессиональная инженерная визитка, а не маркетинговый лендинг или шаблон агентства.

## Запреты
- Никаких эмодзи в интерфейсе.
- Никаких случайных стоковых картинок, AI-генерированных скриншотов, фальшивых dashboard-макетов.
- Никаких гигантских градиентов, glassmorphism, glowing blobs, 3D-объектов, параллакса, каруселей, автопрокрутки, счетчиков, прогресс-баров «PHP 95%».
- Не использовать декоративные иконки в каждой карточке; допустимы простые монохромные SVG для theme switch, внешних ссылок и навигации.
- Никаких цветных бейджей статуса ради украшения.

## Палитра — токены
Светлая тема по умолчанию:
- `--bg: #FAFAF9`
- `--surface: #FFFFFF`
- `--text: #20242B`
- `--muted: #64748B`
- `--border: #E5E7EB`
- `--accent: #4169A8`
- `--accent-soft: #E8EDF5`

Темная тема:
- `--bg: #111418`
- `--surface: #1B2027`
- `--text: #F1F3F5`
- `--muted: #9CA8B7`
- `--border: #303741`
- `--accent: #82A7DC`
- `--accent-soft: #293442`

Применять через CSS custom properties; Tailwind должен ссылаться на семантические токены, а не дублировать цвета в десятках классов. Проверить WCAG AA для основного текста и интерактивных элементов.

## Типографика
- Системный стек: `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`. Не подключать внешние шрифты на старте; Inter — только если доступен локально.
- Основной текст 16–18px, line-height 1.6–1.75.
- H1: clamp(2.25rem, 5vw, 4.25rem), font-weight 600–700, line-height ~1.12, letter-spacing -0.035em.
- H2: clamp(1.65rem, 3vw, 2.25rem), line-height ~1.2.
- Мелкие метки 12–13px, без чрезмерного uppercase.
- Длина строки технического текста — около 65–75 символов.

## Компоновка
- Общий контейнер: max-width 1120px, горизонтальные поля 24px desktop / 20px mobile.
- Длинные тексты кейсов: max-width 760px.
- Вертикальные отступы секций: 88–112px desktop, 56–72px mobile.
- Header: компактный, логотип-текст «Илья Волков», навигация «Проекты», «Обо мне», переключатели RU/EN и Light/Dark. Без липкой шапки на первом этапе.
- Hero: слева выровненный текст, без портрета и иллюстраций. Короткая роль, выразительный H1, 2–3 строки пояснения, две ссылки: «Смотреть проекты» (якорь) и «GitHub».
- Featured: 3 крупные карточки; desktop 1 колонка или асимметричная сетка 2+1 только если не ухудшает читаемость. На mobile всегда 1 колонка.
- Additional: 2 компактные карточки.
- Footer: GitHub, email/LinkedIn только после подтверждения актуальности адресов; copyright без лишних элементов.

## Карточки проектов
- Surface + border 1px, radius 12px, padding 24–32px.
- Сверху порядковый номер и ненавязчивая метка `Private project`.
- Заголовок 22–28px, короткое описание проблемы, 1–2 предложения об инженерном фокусе.
- Стек в виде простой текстовой строки или нейтральных маленьких тегов; максимум 5–6 технологий.
- Внизу текстовая ссылка «Подробнее о проекте» со стрелкой; вся карточка может быть ссылкой, но обеспечить корректный focus.
- Hover: мягкое изменение border/accent или translateY(-2px) с transition 150–200ms; отключать движение при prefers-reduced-motion.

## Темы
- Light — первоначальная тема, если пользователь не выбирал тему.
- Переключатель Light/Dark в header; `localStorage` сохраняет выбор.
- Перед первым рендером применять сохраненную тему маленьким inline-скриптом в `<head>`, чтобы избежать flash неправильной темы.
- Не переключаться автоматически по системной теме при отсутствии сохраненного выбора: по ТЗ светлая тема по умолчанию.
- Обеспечить доступность: `button`, aria-label, aria-pressed, видимый focus ring, клавиатура.

## Локализация
- RU по умолчанию, EN по переключателю. Переключение ведет на эквивалентную страницу другого языка, если она существует; иначе на главную соответствующего языка.
- В header компактный RU / EN, активный язык очевиден.
- Все элементы интерфейса и содержимое кейсов переведены, не смешивать языки в одном абзаце, кроме терминов и технологий.

## Responsive
- Mobile-first: 320px+, без горизонтального скролла.
- До 768px: одна колонка, навигация компактная и доступная без сложного hamburger-меню, если помещается; при необходимости отдельная кнопка меню.
- Tablet 768–1024px: адаптивная сетка без тесных карточек.
- Desktop: контент не растягивается на всю ширину.

## Доступность и качество
- Семантические `header`, `nav`, `main`, `section`, `article`, `footer`; один H1 на страницу.
- Контраст, keyboard navigation, skip link, понятные ссылки, aria-label, reduced-motion.
- Не добавлять картинки без реального контента; если появятся согласованные скриншоты — использовать Astro Image и корректный alt.
- Дизайн должен быть узнаваемым за счет пропорций и типографики, а не декоративных эффектов.
