# Первое задание для Codex

Изучи `README.md`, `PROJECT_CONTEXT.md`, `DESIGN.md`, `ARCHITECTURE.md`, `CONTENT.md` и `AGENTS.md`. Это обязательная спецификация, особенно `DESIGN.md`.

Создай MVP персонального портфолио Ильи Волкова на Astro + Tailwind CSS для GitHub Pages (`iamentrepreneur.github.io`). Реализуй главную страницу RU/EN, страницы «Обо мне» RU/EN, пять страниц кейсов RU/EN, переключение Light/Dark с сохранением выбора, адаптивную верстку, семантическую разметку, метаданные SEO и GitHub Actions workflow для статического деплоя.

Сначала предложи короткий план и структуру файлов. Затем реализуй без дополнительных согласований мелких технических решений, строго придерживаясь документации. Не добавляй сторонние UI библиотеки, backend, CMS, формы, анимации или фиктивные скриншоты. Не публикуй и не создавай репозиторий без моего отдельного разрешения.

После реализации запусти production build и сообщи результаты, ограничения и TODO. Если для кейсов не хватает достоверных деталей, используй только подтвержденные сведения из `CONTENT.md` и явно пометь недостающие места, не придумывай факты.
